# Фотографии сайта

Все фото сейчас — **временные заглушки** с [Unsplash](https://unsplash.com) (лицензия Unsplash: бесплатно, в том числе для коммерческого использования, указывать автора не обязательно). Их нужно заменить на фото с ваших реальных объектов: сайт прораба продают настоящие фото, а не красивые картинки из интернета.

Как заменить фото:

1. Подготовьте своё фото нужных пропорций (см. таблицу) и сохраните в формате **WebP** или **JPG**. Сжать можно бесплатно на [squoosh.app](https://squoosh.app): WebP, качество 75–80, длинная сторона — как в таблице.
2. Самое простое — назвать новый файл так же, как старый, и заменить его в этой папке. Тогда в HTML ничего менять не нужно.
3. Если имя другое — найдите старое имя в `index.html` / `portfolio.html` / `assets/js/portfolio.js` и замените. Над каждым `<img>` в HTML есть комментарий `<!-- ФОТО ЗАМЕНИТЬ: ... -->` с подсказкой.
4. Не забудьте поправить `alt` — короткое описание того, что на фото (для поиска и для незрячих).

Советы по съёмке: снимайте днём при выключенном свете, телефон держите ровно (вертикали не заваливать), уберите мусор и инструмент из кадра. Для «до/после» снимайте с одной точки.
